## 3. Утилиты ввода: чтение чисел и валидация

**Почему так:** консольный ввод — главный источник ошибок, надо вынести и переиспользовать.

**Результат:** класс `util/InputUtils`:
- `readPositiveDouble(Scanner sc, String prompt)`
- `readInt(Scanner sc, String prompt)`
- `pause(Scanner sc)`

Требования:
- принимать `double` (в т.ч. `3.5`),
- отлавливать нечисловой ввод,
- требовать `> 0`,
- не падать, а просить повторить ввод.

**Коммит:** `feat(cli): add input validation utilities`

---

## 4. UI-слой: общий цикл приложения (скелет)

**Результат:** появляется управляющий класс `ui/ConsoleUI` и точка входа `App`.

1) `App.main()` создаёт `ConsoleUI` и вызывает `run()`.
2) В `ConsoleUI.run()` реализовать:
- печать заголовка;
- ввод `a` и `b` через `InputUtils`;
- создание `Rectangle`;
- переход к меню.

На этом шаге меню может быть **заглушкой** (пока без действий).

**Коммит:** `feat(cli): implement CLI flow (enter params -> menu -> actions)`

## 5. Меню: вывод пунктов и обработка выбора (минимум)

**Результат:** рабочее меню с пунктами **1, 2 и выход**.

1) Написать `printMenu(rect)`.
2) Считать `choice` (целое) через `readInt`.
3) Реализовать обработку:
- `1` → периметр
- `2` → площадь
- `7` (или `0`, если вы так решили) → выход
- иначе → сообщение об ошибке и повтор меню

**Коммит:** `feat(cli): add menu with perimeter/area and exit`
