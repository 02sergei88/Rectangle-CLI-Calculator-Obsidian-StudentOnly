
## Техническое задание

### Учебный проект: CLI-калькулятор характеристик прямоугольника


### 1) Цель работы

Разработать консольное приложение, которое:

1. запрашивает у пользователя параметры прямоугольника (длина и ширина),
    
2. показывает меню операций,
    
3. по выбранной операции вычисляет характеристики фигуры и выводит результат,
    
4. позволяет повторять вычисления или вводить новые параметры.
    

---

## 2) Термины и обозначения

- **a** — длина прямоугольника
    
- **b** — ширина прямоугольника
    
- **P** — периметр
    
- **S** — площадь
    
- **d** — диагональ
    

---

## 3) Функциональные требования

### 3.1. Ввод параметров

Приложение при запуске должно запросить:

- длину `a`
    
- ширину `b`
    

Требования к вводу:

- допускаются **вещественные числа** (например `12`, `3.5`, `0.25`);
    
- значения должны быть **строго больше 0**;
    
- при ошибке ввода приложение **не завершается**, а просит повторить ввод (с понятным сообщением).
    

---

### 3.2. Меню операций

После корректного ввода `a` и `b` приложение выводит меню с операциями.

Минимальный набор:

1. Вычислить периметр `P = 2(a + b)`
    
2. Вычислить площадь `S = a · b`
    

Дополнительные характеристики (чтобы было интереснее и «не только два пункта»):  
3. Диагональ `d = √(a² + b²)`  
4. Длина окружности описанной окружности (окружность через все вершины прямоугольника):  
`C = 2πR`, где `R = d/2`, то есть **C = π · d**  
5. Радиус вписанной окружности — **только если это квадрат** (`a == b` с допуском):  
`r = a/2`  
Если прямоугольник не квадрат — выводить сообщение «Вписанная окружность существует только для квадрата».  
6. Ввести новые параметры (снова запросить `a` и `b`)  
7. Выход

Требования:

- пользователь выбирает пункт меню вводом целого числа;
    
- при неизвестном пункте — сообщение об ошибке и повторный показ меню;
    
- после выполнения операции результат выводится и меню показывается снова (пока не выбран выход или ввод новых параметров).
    

---

### 3.3. Формат вывода результатов

- выводить название вычисляемой величины, формулу (можно кратко) и числовой результат;
    
- округление: **до 2 знаков** после запятой (или больше — по решению студента, но единообразно).
    

---

## 4) Нефункциональные требования

### 4.1. Структура проекта (минимум)

Рекомендуемое разбиение:

- `Rectangle` (класс модели): хранит `a`, `b`; методы вычислений (`perimeter()`, `area()`, `diagonal()`…)
    
- `ConsoleUI` (или `App`): ввод/вывод, меню, цикл приложения
    
- (опционально) `InputValidator`: проверка и повтор ввода
    

### 4.2. Качество кода

- понятные имена переменных;
    
- отсутствие дублирования кода;
    
- обработка ошибок ввода (`try/catch` или аналог);
    
- комментарии по делу (почему так, а не «что и так видно»).
    

---

## 5) Сценарии работы (Use Cases)

### UC-1: Успешный ввод и вычисление площади

1. пользователь запускает программу
    
2. вводит `a`, `b`
    
3. выбирает пункт `2`
    
4. программа выводит площадь
    
5. программа возвращается в меню
    

### UC-2: Ошибка ввода параметра

1. пользователь вводит `a = -5` или `abc`
    
2. программа сообщает об ошибке
    
3. программа повторяет запрос параметра
    

### UC-3: Ввод новых параметров

1. пользователь в меню выбирает `6`
    
2. программа снова запрашивает `a`, `b`
    
3. после ввода возвращается в меню

## 7) Критерии приемки (чек-лист)

Проект засчитывается, если:

- программа не падает на некорректном вводе (буквы, пустая строка, отрицательные числа);
    
- реализованы минимум пункты 1–2 меню + выход;
    
- есть цикл меню (после операции можно выбрать следующую);
    
- есть возможность ввести новые параметры без перезапуска;
    
- формулы считаются корректно;
    
- код структурирован (не всё в одном `main`).
