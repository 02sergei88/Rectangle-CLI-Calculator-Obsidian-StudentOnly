
# Rectangle GUI Calculator

Учебный проект по дисциплине **Java SE**.  
Приложение предназначено для вычисления характеристик прямоугольника и реализовано в двух итерациях: **CLI** и **GUI (JavaFX)**.

---

## 📌 Функциональность

Приложение позволяет:

- вводить параметры прямоугольника (длина `a` и ширина `b`);
    
- вычислять:
    
    - периметр;
        
    - площадь;
        
    - диагональ;
        
    - длину описанной окружности;
        
    - радиус вписанной окружности (только для квадрата);
        
- работать в графическом интерфейсе (JavaFX).

## ▶ Запуск проекта

### 1️⃣ Запуск из Eclipse (рекомендуется для разработки)

В **Run Configuration** необходимо указать VM arguments:

```
--module-path "c:\javafx-sdk-25.0.1\lib"
--add-modules javafx.controls,javafx.fxml
```

После этого проект запускается кнопкой **Run**.

---

### 2️⃣ Запуск JAR-версии

В корне проекта присутствует файл:

```
Rectangle-GUI-Calculator.jar
```

Для запуска используется команда:

```
java --module-path "c:\javafx-sdk-25.0.1\lib" --add-modules javafx.controls,javafx.fxml -jar Rectangle-GUI-Calculator.jar
```

Также в репозитории присутствует файл `run.cmd`, позволяющий запустить приложение двойным кликом.

---

### 3️⃣ Запуск EXE-версии (без JVM / JRE)

В проекте предоставляется **EXE-версия приложения**, созданная с использованием `jpackage`.

Особенности:

- запуск двойным кликом;
    
- наличие встроенной Java Runtime;
    
- установка Java на машине пользователя **не требуется**.
